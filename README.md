# Smart Utility Toolkit

A Node.js-based backend lab assignment developed for **Web Dev III (Node.js & Express Backend)**. This project demonstrates fundamental backend concepts using only Node.js built-in core modules.

## 📌 Assignment Details

- **Course:** Web Dev III (Node.js & Express Backend)
- **Unit:** Unit 1
- **Assignment:** Lab Assignment 1 – Smart Utility Toolkit
- **Technology:** Node.js
- **Language:** JavaScript (ES6)

## 🚀 Project Overview

The Smart Utility Toolkit is a collection of small Node.js utilities designed to demonstrate:

- Command-line interaction
- Custom module creation and reusability
- HTTP server development
- File handling and CRUD operations
- Random number generation
- Basic routing
- Console-based execution and debugging

The project uses Node.js core modules such as `process`, `http`, `fs`, and `crypto`.
